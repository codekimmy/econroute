# Blogger 초기 설정 — 경제 내비 (econroute.blogspot.com)

blogger.com 대시보드 왼쪽 메뉴 기준입니다. 화면 표기는 Blogger 업데이트에 따라 조금 다를 수 있습니다.

## 1. 설정 (기본)

| 항목 | 입력값 |
| --- | --- |
| 제목 | 경제 내비 |
| 설명 | 세계경제에서 내 지갑까지, 길 안내 — ECON ROUTE. 국제 뉴스가 금리·환율·물가를 거쳐 내 지갑에 닿는 경로와 도착 시간을 데이터로 안내합니다. |
| 블로그 언어 | 한국어 |
| 시간대 | (GMT+09:00) 서울 |
| 메타 태그 > 검색 설명 사용 | 켜기, 위 설명 붙여넣기 (글마다 검색 설명도 따로 입력) |
| 댓글 | 처음엔 '로그인 사용자'로 시작해 스팸 관리 |
| HTTPS 리디렉션 | 켜기 |

## 2. 테마

1. 테마 > 반응형 기본 테마 중 **Contempo** 또는 **Essential** 적용 (모바일 우선)
2. 테마 > 맞춤설정 > 고급 > **CSS 추가**에 `blogger/wes.css` 내용 전체 붙여넣기
3. 글꼴: 맞춤설정에서 본문을 고딕 계열로 (IBM Plex Sans KR은 테마 HTML에 Google Fonts 링크를 넣어야 적용 — 2단계에서 진행)

## 3. 레이아웃 (가젯)

| 위치 | 가젯 | 내용 |
| --- | --- | --- |
| 본문 위 | HTML/JavaScript '오늘의 신호등' | `<div id="wes-signals"></div>` + `signal-widget.js` 스크립트 (GitHub Pages 연결 후) |
| 사이드바 | 라벨 | 시리즈 라벨만 표시 |
| 사이드바 | 페이지 | 고정 페이지 목록 |
| 바닥 | HTML/JavaScript '용어 팝업' | `glossary-popup.js` 스크립트 (GitHub Pages 연결 후) |

## 4. 라벨 체계 (메뉴 = 라벨)

- **시리즈:** 오늘의 신호등 · 경로 안내 · 지나온 길 · 경로 재탐색 · 운행 기록 · 초보 운전 · 이정표
- **산업:** 반도체 · 에너지 · 자동차 · 금융
- **자산:** 금리 · 환율 · 원유 · 주식 · 원자재 · 가상자산
- **국가:** 한국 · 미국 · 중국 · 유럽 · 일본 · 중동

상단 메뉴 6개는 페이지 가젯 또는 링크 목록으로 각 라벨 주소(`/search/label/경로 안내`)에 연결합니다.
